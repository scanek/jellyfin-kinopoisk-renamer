# Jellyfin Kinopoisk Renamer

Автоматический органайзер и переименовыватель медиафайлов для **Jellyfin** и **qBittorrent** с умным поиском русских названий через **Kinopoisk API**.

---

## 🌟 Возможности
- 🎬 **Поиск названий через Кинопоиск:** автоматически переводит транслит (`Rezervaciya` ➔ `Резервация`) и зарубежные релизы (`The Gentlemen` ➔ `Джентльмены`) с проверкой года и типа (фильм / сериал).
- 📺 **Организация сериалов:** раскладывает серии по папкам сезонов (`Season 01`), переименовывает эпизоды в стандартный вид `Имя Сериала (Год) - S01E01.ext`.
- 📁 **Фильмы в отдельные папки:** упаковывает отдельные видеофайлы фильмов в структуру `Название Фильма (Год)/Название Фильма (Год).ext`, необходимую для корректного подтягивания постеров и фонов в Jellyfin.
- 💬 **Синхронизация сопутствующих файлов:** вместе с видео синхронно переименовываются субтитры (`.srt`, `.ass`, `.vtt`) и файлы превью/кадров серий (`-thumb.jpg`). Сохраняются постеры, фанарты и NFO.
- 🔒 **Автоматические права доступа (PUID/PGID):** назначает корректные права (`0777` на каталоги, `0666` на файлы) и владельца, исключая появление недоступных для Jellyfin файлов из-под пользователя `root`.
- 🔄 **Авто-обновление библиотеки Jellyfin:** сразу после завершения закачки и переименования отправляет запрос в API Jellyfin для моментального обновления библиотеки без ожидания планового сканирования.
- ⚡ **Кэширование запросов:** сохраняет найденные соответствия в локальный `kp_cache.json`, экономя бесплатный суточный лимит Кинопоиска (500 запросов/день).

## 🔑 Где взять необходимые ключи

1. **Ключ Кинопоиска (`kinopoisk_api_key`):**
   * Зарегистрируйтесь на сайте [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/).
   * В личном кабинете бесплатно выдается API-токен (бесплатный тариф: 500 запросов в день).
2. **Ключ Jellyfin (`jellyfin_api_key`):**
   * Откройте веб-интерфейс Jellyfin с учетной записью администратора.
   * Перейдите: **Панель управления** ➔ **Дополнительно** ➔ **Ключи API**.
   * Нажмите кнопку **«+»**, введите имя (например, `Renamer`) и скопируйте созданный токен.

## ⚙️ Настройка конфигурации (`config.json`)

Скрипт ищет файл конфигурации **`config.json` в той же папке, где лежит сам скрипт `jellyfin_renamer.py`** (а также в каталоге запуска или по системным путям вроде `/config/scripts/config.json`).

### Шаг 1. Создание файла конфигурации
В папке со скриптом создайте копию файла-образца `config.example.json`:
```bash
cp config.example.json config.json
```

### Шаг 2. Заполнение параметров
Откройте `config.json` в текстовом редакторе и укажите ваши данные:

```json
{
  "kinopoisk_api_key": "ВАШ_ТОКЕН_КИНОПОИСКА",
  "jellyfin_url": "http://192.168.1.2:8096",
  "jellyfin_api_key": "ВАШ_КЛЮЧ_API_JELLYFIN",
  "puid": 1000,
  "pgid": 1000,
  "action": "move",
  "rename_folders": true
}
```

#### Описание полей:
| Параметр | Описание | По умолчанию |
| :--- | :--- | :--- |
| `kinopoisk_api_key` | Токен API с сайта kinopoiskapiunofficial.tech | `""` |
| `jellyfin_url` | Полный адрес вашего сервера Jellyfin с портом | `"http://localhost:8096"` |
| `jellyfin_api_key` | Токен API из панели управления Jellyfin | `""` |
| `puid` / `pgid` | UID и GID пользователя на сервере для прав на файлы (например, `1000`) | Наследуются от родительской папки |
| `action` | Действие над файлами: `move` (перемещение), `hardlink` или `copy` | `"move"` |
| `rename_folders` | Переименовывать ли внешнюю папку релиза торрента | `true` |

> 🛡️ **Безопасность:** Файл `config.json` и файл кэша `kp_cache.json` уже добавлены в `.gitignore`. Ваши приватные ключи никогда не попадут в репозиторий Git.

## 🚀 Варианты использования

### Вариант 1. Автоматизация в qBittorrent (Docker / NAS)
*Наиболее популярный сценарий для домашних серверов и NAS (OpenMediaVault, Synology, Unraid, TrueNAS, Debian/Ubuntu).*

1. **Скопируйте файлы скрипта** в постоянную папку конфигурации qBittorrent на хосте:
   Например, если у вас контейнер qBittorrent монтирует `/volume1/docker/qbittorrent/config` ➔ `/config`:
   ```bash
   mkdir -p /volume1/docker/qbittorrent/config/scripts
   cp jellyfin_renamer.py auto_renamer.sh config.json /volume1/docker/qbittorrent/config/scripts/
   chmod +x /volume1/docker/qbittorrent/config/scripts/*.sh /volume1/docker/qbittorrent/config/scripts/*.py
   ```

2. **Настройте qBittorrent:**
   * Откройте Web-интерфейс qBittorrent: **Инструменты** ➔ **Настройки** ➔ **Загрузки**.
   * Прокрутите страницу до раздела **«Запустить внешнюю программу при завершении торрента»**.
   * Включите галочку и вставьте команду:
     ```bash
     /config/scripts/auto_renamer.sh "%F" "%L" "%N"
     ```
     *где:*
     * `%F` — путь к скачанным файлам раздачи на диске.
     * `%L` — категория торрента (`movies` или `series`).
     * `%N` — имя торрента.

3. **Готово!** Теперь при скачивании любого фильма или сериала qBittorrent автоматически вызовет скрипт, файлы разложатся по сезонам, получат русские названия, правильные права доступа, и в Jellyfin немедленно обновится медиатека.

---

### Вариант 2. Ручной запуск из терминала (CLI)

Скрипт можно запускать вручную для отдельных релизов или сразу для целых папок/библиотек.

```bash
# 1. Безопасный тестовый запуск (dry-run — только показывает изменения, не трогая файлы):
python3 jellyfin_renamer.py --dry-run /path/to/media/movies

# 2. Пакетное переименование всех фильмов в папке:
python3 jellyfin_renamer.py /path/to/media/movies

# 3. Пакетное переименование всех сериалов:
python3 jellyfin_renamer.py /path/to/media/series

# 4. Переименование одного конкретного релиза:
python3 jellyfin_renamer.py "/path/to/media/series/Rezervaciya (2026)"
```

#### Дополнительные полезные ключи:
* `--dry-run` — тестовый режим без изменения файлов на диске.
* `--no-kp` — не запрашивать Кинопоиск (оставить оригинальные названия латиницей, только очистить теги качества и разложить сезоны).
* `--no-rename-folder` — переименовать файлы серий внутри, но не менять имя корневой папки.
* `-h`, `--help` — показать справку по аргументам.

> 💡 **Совет:** Вы можете добавить псевдонимы в ваш `~/.bashrc`:
> ```bash
> alias jrename='python3 /path/to/jellyfin_renamer.py'
> alias jtest='python3 /path/to/jellyfin_renamer.py --dry-run'
> ```

### Вариант 3. Использование через Docker

Если вы предпочитаете изолированные контейнеры:

```bash
# Сборка образа:
docker build -t jellyfin-kinopoisk-renamer .

# Запуск сухого прогона через контейнер:
docker run --rm \
  -v /path/to/media:/media \
  -e KINOPOISK_API_KEY="ВАШ_КЛЮЧ" \
  -e JELLYFIN_URL="http://host.docker.internal:8096" \
  -e JELLYFIN_API_KEY="ВАШ_КЛЮЧ" \
  jellyfin-kinopoisk-renamer --dry-run /media/movies
```

Или настройте готовый `docker-compose.example.yml`.

## 📋 Логирование

Скрипт автоматически записывает историю своей работы в файл `renamer.log` рядом со скриптом (или по системному пути `/config/scripts/renamer.log`).

Чтобы наблюдать за процессом в реальном времени:
```bash
tail -f renamer.log
```
